# Phase authoring: surface phases and author them where a spawn is edited

## Goal

Replace the typed phase number in the spawn inspector with a named phase picker (names from `phase_name`, counts from the loaded area), and let the user create a phase and put phases on areas, all through the existing draft/undo/change-history pipeline.

Assumptions (verify in Task 1, do not assume silently):

1. TrinityCore master's `phase_name` is `ID int unsigned PK`, `Name varchar(100) NOT NULL`, and `phase_area` is `AreaId int unsigned`, `PhaseId int unsigned`, `Comment varchar(255)`, PK `(AreaId, PhaseId)`. TrinityCore's schema docs are authoritative; the live database is the tie-breaker.
2. AzerothCore has no `phase_name`/`phase_area` for 3.3.5; its phases are `phaseMask` bits only. Both catalogs keep that split.
3. Godot 4 C# APIs used below (`PopupMenu.AddItem`, `IdPressed`, `Popup()`, `AcceptDialog.Confirmed`, `LineEdit`) exist as written; if a signature differs the compiler says so in Task 6/12.

Out of scope (do not add): `game_event` timeline and event membership, `conditions` source 26 editing, phase groups (`PhaseGroup`) naming, minimap area overlays, preview filtering by `PhaseGroup` (already tracked in `docs/plans/editor-plan.md:442`).

## Architecture

Phases become one shared model (`PhaseName` + the existing `PhaseInfo`/`PhaseCatalog`) with one label builder (`PhaseLabels`) used by the spawn inspector, the phase menu and later the visibility preview. The inspector stops typing `PhaseId` and opens a `PopupMenu` of named phases with area counts; selecting one sends the number through the existing `SpawnFields.Apply` path, so undo, drafts, the `acworld` change log and SQL export are unchanged. Writing a phase is a plain `phase_name`/`phase_area` `RowEdit`, staged like any other edit.

```csharp
namespace ACWorldEdit.Foundation;

/// <summary>
/// How a phase is written for people: its name when the server has one, otherwise its number, plus how
/// many spawns use it. One implementation, so the spawn inspector, the phase menu and the visibility
/// preview never word the same phase differently.
/// </summary>
public static class PhaseLabels
{
    /// <summary>"Hallow's End (12)", "Phase 7", or "Phase 1 (normal world)" on AzerothCore.</summary>
    public static string Name(uint id, string name, bool normalWorldIsOne = false) =>
        name.Length > 0 ? $"{name} ({id})"
        : id == 1 && normalWorldIsOne ? "Phase 1 (normal world)"
        : $"Phase {id}";

    /// <summary>"no spawns here", "1 spawn", "1,204 spawns".</summary>
    public static string Count(int spawns) => spawns switch
    {
        0 => "no spawns here",
        1 => "1 spawn",
        _ => $"{spawns:N0} spawns"
    };

    public static string WithCount(uint id, string name, int spawns, bool normalWorldIsOne = false) =>
        Name(id, name, normalWorldIsOne) + " · " + Count(spawns);
}
```

```csharp
    /// <summary>Every named phase, for the picker; bounded so a damaged table cannot hang the UI.</summary>
    public static async Task<IReadOnlyList<PhaseName>> ReadNamesAsync(WorldReadSession session, CancellationToken token)
    {
        if (!session.Has("phase_name.ID") || !session.Has("phase_name.Name"))
        {
            return [];
        }

        await using var command = session.Command("SELECT ID,Name FROM phase_name ORDER BY ID LIMIT 4096");
        List<PhaseName> names = [];
        await using var reader = await command.ExecuteReaderAsync(token).ConfigureAwait(false);
        while (await reader.ReadAsync(token).ConfigureAwait(false))
        {
            names.Add(new(reader.GetUInt32(0), reader.GetString(1)));
        }

        return names;
    }
```

```csharp
namespace ACWorldEdit.Foundation;

/// <summary>
/// The phase list a picker shows: every named phase plus every phase the loaded area counts, in ID order,
/// each worded once through <see cref="PhaseLabels"/>. Pure data, so the inspector, the sideways switch and
/// the tests agree on what a phase is called.
/// </summary>
public static class PhaseMenu
{
    public static IReadOnlyList<(uint Id, string Label)> Items(
        IEnumerable<PhaseName> names, PhaseCatalog counts, bool azerothCore)
    {
        var byId = names.GroupBy(n => n.Id).ToDictionary(g => g.Key, g => g.First().Name);
        var spawns = counts.Phases.ToDictionary(p => p.Id, p => p.Spawns);
        var ids = byId.Keys.Concat(spawns.Keys);
        if (azerothCore)
        {
            // Phase 1 is the normal world: always offerable, even in an area with no spawns yet.
            ids = ids.Append(1u);
        }

        return ids.Distinct().Order()
            .Select(id => (Id: id, Label: PhaseLabels.WithCount(
                id,
                byId.GetValueOrDefault(id, ""),
                spawns.GetValueOrDefault(id, 0),
                normalWorldIsOne: azerothCore)))
            .ToArray();
    }

    /// <summary>The next free phase ID: one past the highest name, so a new phase never collides with a stored one.</summary>
    public static uint NextId(IEnumerable<PhaseName> names) => names.Select(n => n.Id).DefaultIfEmpty(0).Max() + 1;
}
```

```csharp
    /// Show the phase menu for one spawn. Names are read once per connection and cached by the caller;
    /// counts come from the loaded area. "New phase…" is only offered when <paramref name="create"/> is given.
    /// </summary>
    public static void ChoosePhase(Node owner, Func<IDBSource> source, PhaseCatalog counts, Action<uint> picked,
        Func<string, uint?>? create = null)
    {
        var menu = new PopupMenu { Name = "PhaseMenu", HideOnCheckableItemSelection = true };
        const int newPhaseId = -1;
        foreach (var (id, label) in PhaseMenu.Items(Run(source, counts), counts, source().Schema.Dialect == WorldDialect.AzerothCore))
        {
            menu.AddItem(label, (int)id);
        }

        if (create != null)
        {
            menu.AddSeparator();
            menu.AddItem("New phase…", newPhaseId);
        }

        menu.IdPressed += id =>
        {
            if (id == newPhaseId)
            {
                PhaseNameDialog.Ask(owner, name =>
                {
                    if (create(name) is { } created)
                    {
                        picked(created);
                    }
                });
                return;
            }

            picked((uint)id);
        };
        owner.AddChild(menu);
        menu.Position = (Vector2I)owner.GetScreenTransform().Origin + (Vector2I)owner.Size / 2;
        menu.Popup();
        menu.PopupClosed += menu.QueueFree;
    }

    /// <summary>The names read for this click; a failed read offers only the area's counted phases.</summary>
    static IReadOnlyList<PhaseName> Run(Func<IDBSource> source, PhaseCatalog counts)
    {
        try
        {
            return source().ReadPhaseNamesAsync(CancellationToken.None).GetAwaiter().GetResult();
        }
        catch (Exception)
        {
            return counts.Phases.Where(p => p.Name.Length > 0).Select(p => new PhaseName(p.Id, p.Name)).ToArray();
        }
    }
```

```csharp
using System.Globalization;

namespace ACWorldEdit.Foundation;

/// <summary>
/// The row edits a phase change is made of, as ordinary <see cref="RowEdit"/>s so a phase shares the
/// draft, the undo history, the change log and the SQL export with every other edit.
/// </summary>
public static class PhaseEdits
{
    /// <summary>A new named phase; Before is null, so the draft records an insert.</summary>
    public static RowEdit CreatePhase(TableSchema table, uint id, string name)
    {
        string trimmed = name.Trim();
        if (trimmed.Length == 0)
        {
            throw new InvalidDataException("A phase needs a name.");
        }

        return new(table.Name, id.ToString(CultureInfo.InvariantCulture), null,
            Row.Of(("ID", id), ("Name", trimmed)));
    }

    /// <summary>A phase made available in an area.</summary>
    public static RowEdit AddArea(TableSchema table, uint areaId, uint phaseId, string comment) =>
        new(table.Name, $"{areaId.ToString(CultureInfo.InvariantCulture)}|{phaseId.ToString(CultureInfo.InvariantCulture)}", null,
            Row.Of(("AreaId", areaId), ("PhaseId", phaseId), ("Comment", comment.Trim())));

    /// <summary>A phase taken out of an area; the stored row is the baseline so a stale draft is caught.</summary>
    public static RowEdit RemoveArea(TableSchema table, Row before) =>
        new(table.Name, table.KeyOf(before), before, null);
}
```

## Risks, tradeoffs, open questions

- **Schema assumptions.** Tasks 11 and 17 encode `phase_name`/`phase_area` columns. Task 1 verifies them; if they differ, use the database and keep the tests' intent.
- **Synchronous read in the click handler.** `ChoosePhase` reads names with `GetAwaiter().GetResult()` on the main thread — one bounded query, cached per connection by Task 14. If it hitchs, convert `ChoosePhase` to `async void` and `await` the read before opening the menu; the API shape does not change.
- **No conditions yet.** `phase_area` rows decide *where* a phase applies; *when* (quest done, event running) is `conditions` source 26, which needs the Phase 13 builder. This plan shows nothing about it, and `Phase 17` stays `partial` — do not fake a condition column.
- **`game_event` authoring is deliberately out.** The events timeline wants a calendar and event membership in every editor; that is Phase 17 proper. Phases first: an event needs phases to switch between.
- **`PhaseGroup`** remains a typed number until a naming source exists; the tooltip says so (Task 17).
- **Golden churn.** Any new control in the inspector rewrites `Tests/golden/ui-*.json`. Regenerate once, read the diff, and never hand-edit a golden.
- **Open question for the product owner:** should the phase picker be scoped to the loaded area's phases (what the preview shows today) or the server's whole `phase_name` list? This plan shows the union, sorted by ID, with per-area spawn counts, because a phase with no spawns yet is exactly what you need when authoring the first spawn for it.
