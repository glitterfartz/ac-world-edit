# Foundation

Plain `net8.0` library (`ACWorldEdit.Foundation.csproj`), namespace `ACWorldEdit.Foundation`: drafts, spawn authoring, entity pages and rules, change history, SQL generation, tooltips. The Godot app loads it as a plain DLL; `Tests/ACWorldEdit.Tests` references it directly. The server/view coordinate primitives (`WorldCoordinates`, `Point3`, `WorldPose`, `PoseText`) live in `src/ACWorldEdit.Core` (namespace `ACWorldEdit`) because the client-data library needs them too.

## Rules

- Base .NET only. No `using Godot`, no `MySqlConnector`, no archive/format parsers. `Tools/refactor_gate.py` asserts this folder holds no Godot type.
- Dialect-specific classes are `Ac*` / `Tc*` (file names too) in `AzerothCore/` or `TrinityCore/`. Shared interfaces, descriptors, renderers and the one registry that names both dialects stay unprefixed.
- Pick a dialect through `WorldSchemas.For(dialect)`. Never call the AzerothCore statics (`AcTables`, `AcQuestModel`, `AcNpcFlags`) from shared or TrinityCore code; add the missing descriptor to `IWorldSchema`.
- Edits are `RowEdit`s staged in a draft; SQL comes out of `Sql/SqlExport.cs`. Nothing in this project opens a connection or touches a file beyond draft storage.
- Drafts are checksummed JSON envelopes replaced atomically (`Drafts/DraftHistory.cs`). Record property names are the on-disk shape: renaming one breaks saved drafts, so add a field instead.

## Generated files — do not hand-edit

| File | Regenerated by |
|---|---|
| `AzerothCore/AcSmartTypes.cs`, `TrinityCore/TcSmartTypes.cs` | `Tools/generate_smart_catalog.py` (`--trinity` for the TC one) |
| `AzerothCore/AcConditionTypes.cs`, `TrinityCore/TcConditionTypes.cs` | `Tools/generate_condition_catalog.py` |

Both take the upstream server header (AzerothCore / TrinityCore source tree) and the output path; the usage line is at the top of each script. Curated names and labels live in the script, so a wording change belongs there and is then regenerated.

Tests for this layer live in `Tests/ACWorldEdit.Tests` (see `Tests/AGENTS.md`).
