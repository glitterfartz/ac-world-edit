# Progress

Current state only. Update or remove entries as things change; do not append history (git has it).

## Behavior editor (SmartAI, AIName, creature_text, areatrigger_scripts)

- Opens from inspector Behavior…, the interaction window, quest givers and the toolbar/menu. Scopes: creature
  (source_type 0), GameObject-less creature actionlists, and AreaTrigger (source_type 2, `On trigger` event 46 only).
- Rules are edited in the same card as existing rules. **+ Add rule**, templates and "+ Then" open a `PendingRule`
  card that is drafted only by its Add button; Discard drops it. Pickers are grouped by server code keywords
  (93 events / 178 actions / 37 targets; range markers excluded). Catalog is generated by
  `Tools/generate_smart_catalog.py` from SmartScriptMgr.h.
- Shows each rule as a sentence, natural timers and chains; uncurated types show raw labelled parameters with the
  server comment. Speech lines edit `creature_text`; a resolving BroadcastTextId overrides the line text.
- Validates against server loader rules (SmartScriptMgr / ObjectMgr) and fixes AIName. Key-changing edits
  (reorder, Then, delete) are one delete+insert command. New action list IDs come from entry×100+0..99 free of
  database and draft rows.
- All content editors share one `ContentDrafts` file and undo history. Edits are local drafts only.

## Pending Changes / export (uncommitted)

- Pending Changes window lists every net change with per-row Discard, Export All, Discard All; a red
  "Unsaved changes!" button in the Scene explorer opens it. Export writes guarded `-apply.sql` / `-revert.sql`
  per source under `user://exports/<time>/` and records fingerprints in `user://drafts/exported.json`.
- Teleport dropdown (`game_tele`, in `ReadSchema` allowlist) is committed in 9c7e1d4.

  discarded).
- Never run against MySQL: exported SQL syntax and FLOAT/NULL guard behaviour are unproven (no disposable database

  signal.

- Fidelity gaps: equipment/helm/facial hair composition, particles/ribbons, second texture units, portal culling,
